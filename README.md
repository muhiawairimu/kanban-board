# 📋 TaskFlow — Interactive Drag & Drop Kanban Board

A modern, responsive workflow management application built with HTML5, CSS3 (Tailwind CSS), and JavaScript using native HTML5 Drag and Drop APIs.

---

## ✨ Features

- **Native Drag & Drop:** Smooth drag-and-drop task card relocation between columns (*To Do*, *In Progress*, *In Review*, *Done*).
- **Task Management:** Create, edit, and delete tasks with custom descriptions, priorities, and due dates.
- **Priority & Overdue Badges:** Color-coded priority tags (High, Medium, Low) and automatic overdue date indicators.
- **Real-time Search & Filter:** Live keyword search bar and priority dropdown filters.
- **Local Persistence:** Saves all board states and cards across sessions using `localStorage`.
